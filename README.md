# Percorso C1 Inglese

App per arrivare al livello C1 di inglese in 16 settimane, con circa 2 ore di studio al giorno.

**Apri l'app:** https://mariosimone2k.github.io/C1-english/

- Si installa sul telefono: iPhone → Safari → Condividi → "Aggiungi alla schermata Home"; Android → Chrome → menu → "Installa app".
- Funziona anche offline dopo la prima apertura.
- I progressi restano salvati sul dispositivo di chi la usa; ognuno ha i propri.
