# Ascent English

A personalised, day-by-day plan to move up the CEFR levels in English (A2 → B1 → B2 → C1 → C2).

**Open the app:** https://mariosimone2k.github.io/C1-english/

- On first launch you choose your current level, your target level, minutes per day, study days per week, your exam (Cambridge, IELTS or none) and a start date. The plan is built from those choices.
- Each study day has 3 to 5 tasks: flashcards, listening, reading, a daily focus (grammar, writing, conversation, vocabulary, exam practice, review) and speaking.
- Includes grammar lessons with self-marking exercises, themed vocabulary with Italian translations, spaced-repetition flashcards, writing tasks with saved drafts, and a progress log.
- Install it on a phone: iPhone → Safari → Share → "Add to Home Screen"; Android → Chrome → menu → "Install app". It works offline after the first visit.
- Progress is stored on each person's device. Settings has a backup code to move it to another device.

## Files

- `index.html`, `css/app.css`, `js/app.js`: the app
- `js/b1.js`, `js/b2.js`, `js/c1.js`, `js/c2.js`: content for each level reached
- `sw.js`, `manifest.webmanifest`, icons: installable offline app. Bump `CACHE` in `sw.js` after any change so installed copies update.
